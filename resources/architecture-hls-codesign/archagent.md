### Papers

[Agentic AI for Heterogeneous System Design Across Chip, Scale-Up, and Scale-Out Domains](https://arxiv.org/abs/2610.23724) (2026-10-16, preprint) — Introduces ArchAgent, a hierarchical multi-agent framework for chip and system architecture exploration using a deterministic analytical evaluator; reported performance is model-based, rather than measured silicon performance.

## 简体中文

### 论文

[Agentic AI for Heterogeneous System Design Across Chip, Scale-Up, and Scale-Out Domains](https://arxiv.org/abs/2610.23724)（2026-10-16，预印本）— 提出分层多 Agent 框架 ArchAgent，通过确定性的分析评估器探索芯片与系统架构；报告的性能来自模型评估，并非实测芯片性能。
