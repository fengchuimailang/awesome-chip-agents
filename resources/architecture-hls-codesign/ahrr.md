## English

### Papers

[Can Agents Design Better Chips with a Higher Level Abstraction?](https://arxiv.org/abs/2609.21157) (2026-09-17; ICCAD 2026 special session) — Combines agent-based HLS design with post-HLS RTL refinement (AHRR), evaluated on 11 FPGA tasks; includes [code, task definitions, and evaluation artifacts](https://github.com/ZijD/AHRR).

### Open-source Projects

[AHRR](https://github.com/ZijD/AHRR) — Agent-based HLS design and RTL refinement workflow with 11 FPGA task definitions, evaluation harnesses, experiment records, and agent trajectories; reproducing the hardware flows requires Vitis/Vivado.

## 简体中文

### 论文

[Can Agents Design Better Chips with a Higher Level Abstraction?](https://arxiv.org/abs/2609.21157)（2026-09-17；ICCAD 2026 专题会议论文）— 将 Agent 驱动的 HLS 设计与 HLS 后的 RTL 精修结合为 AHRR，在 11 项 FPGA 任务上评测；提供[代码、任务定义和评测材料](https://github.com/ZijD/AHRR)。

### 开源项目

[AHRR](https://github.com/ZijD/AHRR) — Agent 驱动的 HLS 设计与 RTL 精修流程，提供 11 项 FPGA 任务定义、评测框架、实验记录和 Agent 轨迹；复现硬件流程需要 Vitis/Vivado。
