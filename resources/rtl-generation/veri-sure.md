## English

### Papers

[Veri-Sure: Multi-Agent RTL Code Generation with Temporal Tracing, Slicing and Formal Verification](https://arxiv.org/abs/2601.19747) (2026-01-27; revised 2026-10-15) — Coordinates agents through a design contract, dependency-slicing-guided local repairs, temporal trace analysis, and formal verification for RTL generation and debugging; includes [public code and benchmark extensions](https://github.com/xyjoey/Veri-Sure).

### Open-source Projects

[Veri-Sure](https://github.com/xyjoey/Veri-Sure) — Public multi-agent RTL generation and repair implementation using design contracts, dependency slicing, temporal tracing, and formal verification; also includes the VerilogEval-v2-EXT benchmark extension.

## 简体中文

### 论文

[Veri-Sure: Multi-Agent RTL Code Generation with Temporal Tracing, Slicing and Formal Verification](https://arxiv.org/abs/2601.19747)（2026-01-27 首发；2026-10-15 更新）— 通过设计契约协调 Agent，结合依赖切片引导的局部修复、时序轨迹分析和形式验证进行 RTL 生成与调试；提供[公开代码和基准扩展](https://github.com/xyjoey/Veri-Sure)。

### 开源项目

[Veri-Sure](https://github.com/xyjoey/Veri-Sure) — 公开的多 Agent RTL 生成与修复实现，使用设计契约、依赖切片、时序追踪和形式验证；同时包含 VerilogEval-v2-EXT 基准扩展。
