## English

### Benchmarks and Datasets

[SCORE: System-on-Chip Verilog RTL Modules Dataset](https://github.com/SJTU-YONGFU-RESEARCH-GRP/score) — Open dataset of consistently generated Verilog RTL from SoC generators and hardware construction languages, useful for reproducible synthesis, verification, and agent evaluation, but not itself an agent benchmark.

## 简体中文

### 基准与数据集

[SCORE: System-on-Chip Verilog RTL Modules Dataset](https://github.com/SJTU-YONGFU-RESEARCH-GRP/score) — 汇集由 SoC 生成器和硬件构造语言一致生成的 Verilog RTL，可用于可复现的综合、验证和 Agent 评测，但本身不是 Agent 基准。
