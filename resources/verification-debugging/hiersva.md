## English

### Open-source Projects

[HierSVA code and artifacts](https://github.com/HierSVAAnon/HierSVACodeAndArtifacts) — Data synthesis and evaluation pipeline for LLM-driven SystemVerilog assertion generation on hierarchical RTL.

### Benchmarks and Datasets

[HierSVA dataset](https://huggingface.co/datasets/AnonymousHierSVA/HierSVA) — Includes 342 BaseJump STL modules with hierarchy metadata and a deeper subset of module-bug pairs.

[HierSVA: A Data Synthesis Pipeline, Dataset, and Benchmark for LLM-Driven Hierarchical Hardware Formal Verification](https://arxiv.org/abs/2606.13706) (2026-06-09, preprint) — Evaluates assertion syntax, proof success, vacuity, specification faithfulness, mutation coverage, and formal-core coverage.

## 简体中文

### 开源项目

[HierSVA 代码与材料](https://github.com/HierSVAAnon/HierSVACodeAndArtifacts) — 面向层次化 RTL 的 LLM SystemVerilog 断言生成数据构建与评测流程。

### 基准与数据集

[HierSVA 数据集](https://huggingface.co/datasets/AnonymousHierSVA/HierSVA) — 包含 342 个带层次结构元数据的 BaseJump STL 模块，以及更深层次的模块-缺陷样本子集。

[HierSVA: A Data Synthesis Pipeline, Dataset, and Benchmark for LLM-Driven Hierarchical Hardware Formal Verification](https://arxiv.org/abs/2606.13706)（2026-06-09，预印本）— 从断言语法、证明成功率、空洞性、规格忠实度、变异覆盖和形式核心覆盖等维度评测。
