## English

### Benchmarks and Datasets

[CircuitNet](https://github.com/circuitnet/CircuitNet) is a supporting EDA dataset for physical-design ML evaluation, not an agent benchmark by itself. Its original paper, [CircuitNet: An Open-Source Dataset for Machine Learning Applications in Electronic Design Automation (EDA)](https://arxiv.org/abs/2208.01040), was first submitted to arXiv on 2022-08-01; this is the preprint submission date, not a dataset-release date.

## 简体中文

### 基准与数据集

[CircuitNet](https://github.com/circuitnet/CircuitNet) 是用于物理设计机器学习评测的 EDA 支撑数据集，本身并非 Agent 基准。其原始论文 [CircuitNet: An Open-Source Dataset for Machine Learning Applications in Electronic Design Automation (EDA)](https://arxiv.org/abs/2208.01040) 于 2022-08-01 首次提交至 arXiv；此日期为预印本提交日期，并非数据集发布日期。
