## English

ltspice-mcp connects an AI assistant to local circuit simulators and LTspice schematic editing. Its tools support background experiments, parameter sweeps and Monte Carlo setups, result analysis, waveform plots, circuit verification, and a Python API. LTspice or ngspice must be installed separately, and editing .asc schematics requires LTspice. The README marks the project as work in progress and states that macOS is not currently supported. The project uses GPL-3.0.

The date follows the first PyPI release, 0.1.0 on April 6, 2026; the initial repository-publication date has not been established.

## 简体中文

ltspice-mcp 将 AI 助手连接到本地电路仿真器，并提供 LTspice 原理图编辑能力。其工具支持后台实验、参数扫描与蒙特卡洛设置、结果分析、波形绘图、电路验证和 Python API。需要另行安装 LTspice 或 ngspice，编辑 .asc 原理图则需要 LTspice。README 将项目标记为开发中，并说明目前不支持 macOS。项目采用 GPL-3.0。

日期采用首次 PyPI 发布，即 2026 年 4 月 6 日的 0.1.0；仓库最初公开日期尚未确认。
