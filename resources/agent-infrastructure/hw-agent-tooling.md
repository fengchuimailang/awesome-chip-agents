## English

hw-agent-tooling is a landing page for hardware-agent infrastructure. Its MCP server family covers [Verilog](https://github.com/zesun33/mcp-verilog), [cocotb](https://github.com/zesun33/mcp-cocotb), [Yosys](https://github.com/zesun33/mcp-yosys), [RTL review](https://github.com/zesun33/mcp-rtl-review), [OpenROAD](https://github.com/zesun33/mcp-openroad), [GDS checks](https://github.com/zesun33/mcp-gds), [formal verification](https://github.com/zesun33/mcp-formal), [FPGA](https://github.com/zesun33/mcp-fpga), and [SPICE](https://github.com/zesun33/mcp-spice). It also links shared EDA container images, skills, project scaffolding, and the agentic-asic orchestrator. Each server is maintained and installed from its own repository; this entry catalogs the portfolio as a whole.

The author documents Linux-based container verification; other platforms and component readiness should be checked in the individual repositories. The date comes from the landing page's v0.1.0 changelog and does not date all component servers.

## 简体中文

hw-agent-tooling 是硬件 Agent 基础设施的入口页，其 MCP 服务组合覆盖 [Verilog](https://github.com/zesun33/mcp-verilog)、[cocotb](https://github.com/zesun33/mcp-cocotb)、[Yosys](https://github.com/zesun33/mcp-yosys)、[RTL 审查](https://github.com/zesun33/mcp-rtl-review)、[OpenROAD](https://github.com/zesun33/mcp-openroad)、[GDS 检查](https://github.com/zesun33/mcp-gds)、[形式验证](https://github.com/zesun33/mcp-formal)、[FPGA](https://github.com/zesun33/mcp-fpga) 和 [SPICE](https://github.com/zesun33/mcp-spice)。它还链接共享 EDA 容器镜像、技能、项目脚手架和 agentic-asic 编排器。各服务在独立仓库维护和安装，本条目作为整个工具组合的总览。

作者记录了基于 Linux 的容器验证，其他平台支持与各组件成熟度应查阅相应仓库。日期来自入口页 v0.1.0 更新日志，不代表所有组件服务的发布日期。
